# PEA Read Only Native Read Coverage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `PEA Read Only` sufficient for read-only production-entry operations without assigning `Stock User` or `Manufacturing User`.

**Architecture:** Add native `DocPerm` fixture rows for `PEA Read Only` on the standard doctypes reached by read-only production-entry flows. Use `DocPerm`, not `Custom DocPerm`, because `Custom DocPerm` overrides all standard permission rows for a doctype unless every native role row is copied. Keep runtime code unchanged.

**Tech Stack:** Frappe/ERPNext permissions, app fixtures, Python `FrappeTestCase`, bench migrate/export-fixtures, pre-commit.

- [ ] **Step 1: Insert or update the local DocPerm rows on bench15**

Run from `/root/workspace/bench15`:

```bash
cat <<'PY' | bench --site development.localhost console
import frappe

READ_ONLY_DOCTYPES = (
	"Page",
	"Company",
	"Stock Entry",
	"Stock Entry Detail",
	"BOM",
	"BOM Item",
	"Item",
	"Workstation",
	"Warehouse",
	"UOM",
)

PERMISSION_VALUES = {
	"read": 1,
	"select": 1,
	"write": 0,
	"create": 0,
	"delete": 0,
	"submit": 0,
	"cancel": 0,
	"amend": 0,
	"report": 0,
	"export": 0,
	"import": 0,
	"share": 0,
	"print": 0,
	"email": 0,
}

for doctype in READ_ONLY_DOCTYPES:
	meta_doc = frappe.get_doc("DocType", doctype)
	permission_row = None
	for row in meta_doc.permissions:
		if row.role == "PEA Read Only" and int(row.permlevel or 0) == 0 and int(row.if_owner or 0) == 0:
			permission_row = row
			break

	if permission_row is None:
		permission_row = meta_doc.append(
			"permissions",
			{
				"role": "PEA Read Only",
				"permlevel": 0,
				"if_owner": 0,
			},
		)

	for fieldname, value in PERMISSION_VALUES.items():
		setattr(permission_row, fieldname, value)

	meta_doc.save(ignore_permissions=True)
	frappe.clear_cache(doctype=doctype)

frappe.db.commit()
print("PEA Read Only DocPerm rows prepared:", len(READ_ONLY_DOCTYPES))
exit()
PY
```
